# Noto Sans Regular

`NotoSans-Regular.ttf` is an unmodified font downloaded from the official Noto repository:

https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

License: SIL Open Font License 1.1. See `OFL.txt` for the copyright notice and full license text.

SHA-256: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`.

The font is loaded from this site's own static assets and embedded in vector PDF exports. It provides Latin, Greek and Cyrillic drawing text. Unsupported glyphs cause an explicit export error instead of a silently damaged label.
